# Zuzana Krásová — Psychoterapie

Statický responzivní web pro psychoterapeutku Zuzanu Krásovou.

## Spuštění lokálně

Stačí otevřít `index.html` v prohlížeči, případně spustit jednoduchý statický server:

```bash
python -m http.server 4173
```

Pak otevřete `http://localhost:4173`.

## Obsah

- `index.html` — struktura stránky
- `styles.css` — vzhled včetně jemných hover efektů
- `script.js` — mobilní navigace, plynulé rolování a formulářová zpráva
